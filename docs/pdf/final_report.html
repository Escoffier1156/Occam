3. 信頼性の機構

3.1 出自の型付け

各設定がどこから来たかを型で持つ。監査が1行で済む。

型意味
published公表規則が既に言っている範囲内の置換。新しい化学的主張をしない
relaxation数値閾値を動かしただけ。主張が元から無い
unjustified新しい化学的主張。提案してはならない

3.2 重み付きスコアを使わない

score = w1×生存 + w2×多様性 − w3×penalty    ← 使わない

w は発明物で、「最良」が重みの産物になる。順序は**（緩和ステップ数、出自、決定的タイブレーク）

の辞書式のみ。条件を満たす仕様を全部（上限8）返し、trade は人間が判断する。**

3.3 対照の強制

out_of_domain と「計算が壊れている」は同じ顔をする（禁忌79）。重い判定には

同一の計算経路を既知集合に適用した対照を必ず添える。

対照測定値排除するもの
Tanimoto 経路訓練集合内で中央値 0.747、閾値以上 94.0%指紋の半径・ビット長の不一致、塩や立体化学の残り
globularity公表値68件と r = 0.529、範囲 [0.037, 0.343] 対 [0.046, 0.450]配座が埋まらず全分子が平板に読まれる失敗

globularity の対照は「範囲については通るが分子単位では弱い」と記録している

（12/68 が 0.25 閾値で不一致、配座で最大 0.236 動く）。

3.4 不変条件の機械的保護

不変条件強制の方法
1. carry は固定長#[derive(Copy)] が Vec/HashMap/Box/String を排除。const assert がサイズを固定
2. 1ファイル1行グループparquet フッタが行グループ数に比例するので、2つ以上なら読み込み時に拒否
3. バルク/演算器を同時に1つだけcompare_exchange による排他。2つ目を作ると panic

KeepOut が AST レベルでこれらの領域を封じる。整形・コメント・変数改名は無視し、

構造変更だけを拒否する。third_party/keepout/ に同梱（Apache-2.0）。

不在は skip ではなく失敗。

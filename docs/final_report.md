## 0. 要約

**グラム陰性菌スクリーニングの成立判定システム。**研究者の要求を受け、
**成立する / 成立しない / 代替案（実測から）**の3つを返す。**分子は出力しない。**

| | |
|---|---|
| 規模 | Python 36本、Rust 5本、**11,133行**（テスト除く） |
| テスト | **Python 124本 + Rust 11本** |
| KeepOut ロック | **9箇所**（AST レベル） |
| 禁忌リスト | **86項目**（うち35がテストで機械的に守られている） |
| コミット | 12（すべてローカル、remote 未設定） |
| 外部検証 | **ゼロ** |
| 実験 | **ゼロ**（細胞に触っていない） |

### 責任の境界（商品の文言としてもこれ）

```
❌ 「我々が測り、あなたが判断する」
✅ 「渡すものの整合性は我々の責任。科学的判断はあなたの責任」
```

**科学的な正しさの証明は求めていない。渡したものが要求どおりであることは保証する。**
この保証は 2026-10-09 と -10 に3回破れ、その都度原因を特定して直した（§6）。

## 2. 製品は何を返すか

### 2.1 3本柱

```
プロンプト入力 → バルク処理 → アシスト出力
```

| | 実装 |
|---|---|
| **成立する** | 正確カウント。何ステップの緩和が要るか、frontier で trade を提示 |
| **成立しない** | 上限値と、それを超えるために必要なもの |
| **代替案（実測から）** | ①どのスライスか ②どの訓練集合が最も近いか ③**何件測れば範囲内に入るか** |

### 2.2 拒否が本体

**答えではなく拒否を作るのに時間がかかっている。**

| 拒否 | 条件 |
|---|---|
| 語彙外の値 | MW 500、回転結合6 → **丸めずに停止**、登録値を列挙 |
| 別の量への読み替え | 電荷語（引退 knob）→ スライス選択に黙って回さず停止 |
| **公表ルールとの矛盾** | 中性スライス + イオン化可能窒素 → **分子を1件も読む前に停止**。根拠（陽性12/41、中性0/39）を提示 |
| **障壁の不一致** | eNTRy 条件を BBB ライブラリに → 停止 |
| 事実の主張 | 件数・AUC・骨格数・検証状態 → 破棄して理由付きで一覧 |
| 標的の不在 | ラベルが無い → `cannot be answered` ＋ 実測の代替案 |
| スコープ不一致 | 第1パスと第2パスの読み込み量が違う → 停止 |
| 不可能な計数 | 骨格数 > 生存数 → 落ちる |
| 旧レコード | 引退した knob を含む sweep → 理由を出して拒否 |
| 書き込み不能 | `--out-dir` が作れない → 理由を出して停止 |

### 2.3 拒否の次の一歩

**拒否で終わらせない。**適用範囲外の判定の直下に、それを解消する実験規模が出る。

```
predicting activity: can be answered only by extrapolating past the training set
  median 0.212, max 0.413 against a 0.4 threshold
  positive control: passes
  what would close it: 268 compounds measured, one per neighbourhood
    at Tanimoto 0.4. 115 of them cover half the set, 207 cover four fifths
    239 neighbourhoods hold one compound, so the tail is one purchase each
    the count is a property of the threshold: 0.30: 215, ... moving 1.37x
    this is coverage, not accuracy ... No compound is emitted.
```

**被覆の要件であって精度の約束ではない**ことを同じ場所に書く。

## 3. 信頼性の機構

### 3.1 出自の型付け

各設定が**どこから来たか**を型で持つ。監査が1行で済む。

| 型 | 意味 |
|---|---|
| `published` | 公表規則が既に言っている範囲内の置換。新しい化学的主張をしない |
| `relaxation` | 数値閾値を動かしただけ。主張が元から無い |
| `unjustified` | 新しい化学的主張。**提案してはならない** |

### 3.2 重み付きスコアを使わない

```
score = w1×生存 + w2×多様性 − w3×penalty    ← 使わない
```

w は発明物で、「最良」が重みの産物になる。順序は**（緩和ステップ数、出自、決定的タイブレーク）
の辞書式**のみ。条件を満たす仕様を全部（上限8）返し、**trade は人間が判断する。**

### 3.3 対照の強制

**`out_of_domain` と「計算が壊れている」は同じ顔をする**（禁忌79）。重い判定には
同一の計算経路を既知集合に適用した対照を必ず添える。

| 対照 | 測定値 | 排除するもの |
|---|---|---|
| Tanimoto 経路 | 訓練集合内で中央値 **0.747**、閾値以上 **94.0%** | 指紋の半径・ビット長の不一致、塩や立体化学の残り |
| globularity | 公表値68件と r = **0.529**、範囲 [0.037, 0.343] 対 [0.046, 0.450] | 配座が埋まらず全分子が平板に読まれる失敗 |

globularity の対照は**「範囲については通るが分子単位では弱い」**と記録している
（12/68 が 0.25 閾値で不一致、配座で最大 0.236 動く）。

### 3.4 不変条件の機械的保護

| 不変条件 | 強制の方法 |
|---|---|
| 1. carry は固定長 | `#[derive(Copy)]` が Vec/HashMap/Box/String を排除。`const` assert がサイズを固定 |
| 2. 1ファイル1行グループ | parquet フッタが行グループ数に比例するので、2つ以上なら**読み込み時に拒否** |
| 3. バルク/演算器を同時に1つだけ | `compare_exchange` による排他。2つ目を作ると panic |

**KeepOut が AST レベルでこれらの領域を封じる。**整形・コメント・変数改名は無視し、
構造変更だけを拒否する。`third_party/keepout/` に同梱（Apache-2.0）。
**不在は skip ではなく失敗。**

### 3.5 禁忌リストのテスト化

**82項目まで増えた時点で、リストは読まれなくなっていた。**実効的だったのはテストに
なった項目だけで、文章のまま残った項目は形を変えて踏み直していた（禁忌54 がそれを
言っている）。

| マーク | 意味 | 件数 |
|---|---|---|
| **〔T〕** | 罠が戻るとテストが落ちる | **35** |
| 〔T一部〕 | 一部だけ | 10 |
| 〔文〕 | **文章だけ** | **41** |

変換の過程で**禁忌73 が実装に存在しないことが判明した**（文頭 `must` の処理が無く、
文書が実在しない挙動を記載していた）。**文章をテストに変換した瞬間に食い違いが出た。**
